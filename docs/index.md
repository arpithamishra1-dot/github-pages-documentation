# Frequently Asked Questions

## 1. What is GitHub Pages?

GitHub Pages is a service used to host static websites directly from a GitHub repository.

## 2. What is Markdown?

Markdown is a lightweight language used to format text and documentation.

## 3. Is GitHub Pages free?

Yes, GitHub Pages supports free hosting for public repositories.

## 4. Can we link different pages?

Yes, Markdown links can connect different documentation pages.
